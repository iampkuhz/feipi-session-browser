# 默认隐藏

所有敏感字段默认隐藏，包括：

- 密钥和 token：`<REDACTED>`。
- HTTP 认证 header：`<REDACTED>`。
- 本地绝对路径：使用 `~/` 缩写。
- 用户个人信息：`[已脱敏]`。

UI 展示默认遮盖，不依赖用户手动操作。管理界面如需查看原始值，需要额外确认步骤。

## 显示前确认

以下场景显示敏感字段前必须确认：

- 开发者调试时需要查看原始值。
- 导出报告时需要包含特定字段。
- 用户主动请求查看自己的数据。

确认步骤：明确告知用户将展示的内容、展示目的和展示范围。展示后不在日志中保留原始值。

## 导出策略

导出（JSON、HTML、日志）时遵循：

- 敏感字段值替换为 `<REDACTED>` 或省略。
- 文件命名不含敏感信息。
- 导出文件不包含真实 home 路径。
- 日志中 token 只保留前 4 字符加 `***`。

## 测试策略

测试中遵循：

- fixture 必须使用 synthetic 数据。
- 禁止复制真实 session 文件到 `scripts/tests/`、`java/tests/`。
- 如需真实数据格式，只保留结构，值用占位符替代。
- synthetic fixture 放在 `java/tests/fixtures/synthetic/` 下。

## 报告策略

报告中遵循：

- 不展示完整 token 或密钥。
- 路径使用相对路径或 tilde 缩写。
- 用户数据使用合成样例。
- 错误信息中不包含原始凭证。
