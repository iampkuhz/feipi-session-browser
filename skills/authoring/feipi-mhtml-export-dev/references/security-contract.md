## 敏感字段

导出文件中的敏感字段必须按照 UI 当前脱敏状态处理：

- API key：必须脱敏，显示为 `***` 或前几位加 `***`。
- Authorization header：必须脱敏，不显示完整 token。
- Session ID 和 user ID：按 UI 当前策略处理（如截断显示）。
- 密码和 secret：必须完全脱敏，不在导出文件中出现。

## 原始请求响应

导出文件中可以包含 request/response 的 body 内容，但必须遵循以下规则：

- 如果 UI 当前已对某字段脱敏，导出文件也必须脱敏。
- 如果 UI 显示完整内容，导出文件可以选择完整或脱敏，但必须在导出确认对话框中说明。
- 不允许导出文件中出现 UI 中看不到的额外敏感信息。

## 本地路径

导出文件中不允许包含用户本地文件系统路径：

- 不允许出现用户主目录下的绝对路径（如 macOS 的 user home 目录、Linux 的 home 目录、Windows 的用户目录等）。
- 不允许出现相对路径指向用户本地文件。
- 如果 session 数据中包含本地路径引用，必须脱敏或替换为 `<LOCAL_PATH>` 占位符。

## token 和密钥

- OAuth token、JWT、session cookie 等绝对不允许出现在导出文件中。
- 如果 request header 中包含 `Authorization`、`Cookie`、`X-API-Key` 等，必须脱敏。
- 导出文件不应包含可用于重放请求的认证凭据。

## 导出确认

- 导出前应显示确认对话框，说明导出范围和内容。
- 确认对话框应提示用户检查是否包含敏感信息。
- 用户必须明确确认后才能生成导出文件。
- 导出完成后应提示文件保存位置和大小。
