# DS-010 发行契约

- **平台与启动：** 只验 Apple Silicon macOS。真实归档使用内置 Java 和唯一的 SQLite macOS arm64 native；在隔离环境验证启动和扫描。
- **路径与索引：** 默认按版本建索引；`--index-dir` 优先于 `INDEX_DIR`。显式指向旧版索引时拒绝启动，不迁移、不覆盖。新版从原始会话扫描重建。
- **候选：** 复核同一 SHA/run/attempt 的精确文件集合、安全结构、字节数、SHA-256 和启动证据。用户核对命令见[发行与本机安装](../release/README.md)；清单不是签名。
- **隐私：** 发行验收使用临时索引和合成源，不读取真实会话。
