# README 截图提供说明

首页已经预留图片位置；未上传图片前使用文字占位，不会显示破图。

## 请提供什么

推荐两张 PNG（也可用 WebP；请相应调整首页路径），不要用包含个人数据的原始 session 作为展示样例：

| 建议文件名 | 页面内容 | 想说明的价值 |
|---|---|---|
| `sessions.png` | Projects 或 Sessions，包含列表和项目上下文 | 如何找到历史会话 |
| `session-detail.png` | 会话详情，包含一段对话、工具调用和 Token 信息 | 如何回看一次工作的过程与用量 |

可选补充 `dashboard.png` 展示整体概览。推荐宽度 1440–1920 px，使用同一主题、缩放比例，保持正文清楚可读；单图尽量不超过 1 MB。不需要拼成长图。

## 上传前检查

- 使用虚构项目、示例会话或明确脱敏后的内容。
- 删除用户名、邮箱、绝对路径、内部仓库地址、密钥、token、请求头与真实业务代码。
- 检查浏览器地址栏、工具参数、侧边栏、悬浮提示和展开的详情。
- 使用裁剪或不透明覆盖，不依赖模糊或页面默认隐藏；导出图片后再次检查。

## 怎样交给我

直接在对话中上传两张图片，并注明「对应页面、希望保留的区域、是否已脱敏」即可；也可以放到本目录并提供文件名。我会检查尺寸、清晰度及可见敏感内容，再接入首页。

自行接入时：

1. 把脱敏图片放在本目录，采用上表文件名。
2. 打开根 `README.md`，取消对应图片行的 HTML 注释；不要启用尚未提供的图片。
3. 删除或更新「截图待补」文字。保持图片使用仓库相对路径，不使用本机绝对路径或临时 URL。
4. 用 Markdown/GitHub 预览确认图片能显示，并把图片和 README 一起提交。

首页预留的 Markdown：

```markdown
![项目与会话列表](docs/images/screenshots/sessions.png)
![会话详情与 Token 统计](docs/images/screenshots/session-detail.png)
```

以上路径相对于仓库根 README，不是相对于本说明文件。
