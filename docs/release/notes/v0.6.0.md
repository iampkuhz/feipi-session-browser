# v0.6.0

## 新功能

- Session Detail 新增工具执行追踪：可查看已记录的耗时、命令或参数和执行结果，区分实测与未知。
- Codex 多 Agent 协作视图可追查委派、等待和回传记录。工具结果可跳转到包含该结果的本地输入，并返回原位置。
- 正常扫描与单文件导入都支持工具结果逐项查看；离线 HTML/MHTML 保留已收录的证据，不承诺在线弹窗或跳转等价。

## 修复与工程改进

- 修复部分 Qoder 单文件导入与 Codex 扫描问题，改进扫描失败诊断。单文件 JSONL 导入上限提升至 200 MiB。
- 构建检查提前发现缺少 JDK 模块、Chromium 或临时空间的问题；减少测试重复建索引及重复执行 Web 测试。

## 安装

只支持 Apple Silicon macOS。归档内置 Java，未签名、未公证。请校验下载的 `MANIFEST.SHA256`，将归档解压到空目录，再启动 `app-cli/bin/run serve`。本版本从原始会话重建索引，不迁移或覆盖旧版索引；显式指定 `--index-dir` 时请使用新的空目录。
