# v0.5

- 会话列表、Dashboard 和详情使用更明确的调用、工具、Token 与计时口径。详情可查看同一调用的已记录请求、响应与工具内容，并区分主会话、子 agent 和归属不明的证据。
- Java HTML/MHTML 导出是静态、完整的离线档案，支持原生展开，并保留源中实际记录的正文和归属；它不是在线 Trace、标签页、筛选或弹窗工作台的离线克隆。
- 原生包自带 Java，仍提供 macOS arm64/x64、Linux x64、Windows x64 和需要 Java 25 的 generic ZIP。原生包仅携带目标平台所需的 SQLite native 资源。包未签名、未公证。

旧索引缺失的调用证据会保持未知，不会显示为零或猜测补齐；缺失的历史源、无法精确解析的旧格式，以及源中未记录的 provider 请求或重试，不能凭本次升级恢复。从公开 v0.4 升级时，保留旧安装和原会话源，停服备份整个索引目录，再让 v0.5 正常扫描并检查列表与详情。不要用旧版直接打开已迁移的索引；恢复旧备份时保留原索引路径。见[安装、更新与失败恢复](https://github.com/iampkuhz/feipi-session-browser/blob/v0.5/docs/release/README.md#本机安装与更新)。

已发布的 v0.4 macOS arm64 原生包可显示版本和顶层帮助，但其内置 Java 缺少 `java.naming`，无法启动 `serve`。如需用 v0.4 读取未迁移的备份，请使用公开的 v0.4 generic ZIP 和 Java 25；不要用旧原生包验证恢复。
