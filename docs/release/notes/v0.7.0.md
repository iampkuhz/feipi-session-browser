# v0.7.0

## 会话详情

- 执行过程按轮次阅读，工具输入、结果和耗时跟随对应调用；桌面上可用鼠标和键盘打开 Request、Response 和 Result。
- Codex Side Chat 区分启动说明、真实用户消息、压缩和模型调用。分开显示单次用量、任务累计、估算与缺测，不按推测补齐 Token。

## Dashboard 与扫描

- 修复 Agent 和模型表格下钻。趋势卡分别显示加载、错误、缺测、无数据和实测零，支持重试并保持索引代次一致。
- 有逐响应计量依据的 Codex 侧聊不再被错标；仅启动而无实际活动的侧聊不进索引，不删除源记录。需要本机排查时可显式使用 `scan --token-audit`。

## 安装

只支持 Apple Silicon macOS。归档内置 Java，未签名、未公证。下载并按 `MANIFEST.SHA256` 核对归档后，解压到空目录并运行 `app-cli/bin/run serve`。本版本从原始会话重建索引，不迁移或覆盖旧索引。显式使用 `--index-dir` 时，请指定新的空目录。
