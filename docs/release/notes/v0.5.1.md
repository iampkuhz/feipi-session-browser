# v0.5.1

- 会话列表、Dashboard 和详情使用更明确的调用、工具、Token 与计时口径。详情可查看同一调用的已记录请求、响应与工具内容，并区分主会话、子 agent 和归属不明的证据。
- Java HTML/MHTML 导出是静态、完整的离线档案，支持原生展开，并保留源中实际记录的正文和归属；它不是在线 Trace、标签页、筛选或弹窗工作台的离线克隆。
- 新发行仅支持 macOS arm64（Apple Silicon）。原生包自带 Java 和目标 SQLite native；不提供 Intel Mac、Linux、Windows 或 generic ZIP。包未签名、未公证。

旧索引缺失的调用证据会保持未知，不会显示为零或猜测补齐；缺失的历史源、无法精确解析的旧格式，以及源中未记录的 provider 请求或重试，不能凭本次升级恢复。从公开 v0.4 升级时，保留旧安装和原会话源，停服备份整个索引目录，再让 v0.5.1 正常扫描并检查列表与详情。不要用旧版直接打开已迁移的索引；恢复旧备份时保留原索引路径。

已发布的 v0.4 macOS arm64 原生包可显示版本和顶层帮助，但其内置 Java 缺少 `java.naming`，无法启动 `serve`。如需用 v0.4 读取未迁移的备份，请使用公开的 v0.4 generic ZIP 和 Java 25；不要用旧原生包验证恢复。
